# 装备、黑皇杖与持盾：判断方法

用于整场装备与技能成长分析，以及出装、黑皇杖、不朽之守护和买活专项。字段格式只在 [ledger-schema.md](ledger-schema.md) 维护；整场覆盖见 [submission-protocol.md](submission-protocol.md)。专项只分析所问对象及关联窗口，不扩成全员审计。

## 十人路线与关键取舍

检查十人路线与实际职责是否匹配。出现以下情况时集中展开：装备改变刷钱或参战强势期；补上先手、机动、驱散、生存、控制、救人或拆塔能力；针对敌方关键威胁；明显延误关键战斗；高风险胜负手或挤占买活；有能力却未兑现目标。

六核逐人分析完整路线，四辅助逐人分析承担职责的功能装。每条路线都要解释能力获得顺序、参战窗口与资源匹配；不能以“无争议”免除分析。所有实际改变战斗结构的关键装备需展开，不要求每个小件单列，也不强制每人有最佳决定和最大错误。

每件关键装备解释：`购买/已知持有时间 → 之前缺少的能力与获得后的取舍 → 购买前后相关战斗 → 使用或未覆盖证据 → 个人与队友的战斗结果 → 地图转化`。引用战斗经过时仍须解释装备在其中的作用，不能只写“见F1”。

在 `alternative_and_cost` 中比较实际购买与一个有意义的替代方向（换顺序、延后、保留买活或不同能力）：当时经济能否支持，哪项能力提前/延后，怎样影响下一波目标，失去什么、依赖谁。原选择合理时说明替代方案为何更差，以及什么新信号会改变推荐；资料不足时指出具体缺口。不能仅把“出装合理”作为结论，也不能套用当前胜负推导出装好坏。

实际不存在相关战斗时说明，不补造案例；全部已确认持有者仍须被检查。

## 技能成长与能力升级

整场复盘筛查十人的技能升级顺序、关键天赋及本场适用的其他能力升级选择，识别影响发育、参战、防守、保护或目标转化的关键窗口。分析英雄实际承担的职责与当时团队缺口，不能只按常见加点模板判对错。详细展开确实改变窗口或存在有意义取舍的选择，不逐级抄录十人加点；无显著分歧者可以在其技能评价中简短交代，不能把缺少记录当作没有问题。

先查实际选择记录及其时间、等级或可确认顺序，再核验本场补丁下的机制。数据源未必提供完整升级事件、时间戳、天赋或其他选择记录，不能假定某个 API 字段必然存在；只有顺序时不补造选择分钟，只有最终配置时不倒推出早期加点或此前已获得的能力。无法确定关键选择发生在窗口前还是窗口后，就不能据此断言该波本可使用该能力。记录不足时保留条件比较并点明所缺记录，不用版本常识补齐实际选择。

对重要选择说明：`选择时点/可确认阶段 → 提前获得的能力 → 被延后的能力 → 当时团队策略与下一目标 → 实际是否兑现`。比较一个在当时等级、前置条件、技能点或经济条件下可行的替代方向，说明影响哪条兵线、哪位队友、哪个敌方威胁或哪个目标，以及代价和失效条件；被动等待、反手保护和清线防守同样可以是合理用途。不要把后续才获得的等级或队友资源当成选择时已经具备的条件，也不以最终输赢替代决策评价。

涉及装备带来的能力升级时，装备部分负责购买顺序、资源成本与获得时点，技能部分负责能力选择、职责匹配和使用效果，相互引用关键结论；同一选择的完整论证只写一次。十人职责评价引用其实际影响，不再重抄升级过程。

## 组件流、拆分与出售

`purchase_time` 汇总不是逐笔事件，口径见 [数据获取协议](data-access.md#时间与字段口径)。购买日志不可靠记录出售，也不证明送达或在主背包；重复成装、组件复用或最终栏位缺失可能来自拆分、重组、出售、消耗或赠送。

发现这些信号或玩家提供拆卖回忆时，检查组件前后去向、重复购买和最终库存。相容回忆作为“玩家复述”保留，不能据此篡改原始日志；无法区分时说明组件流不能完全确认，修正此前装备真空期判断。

评价拆卖比较损失、提前获得能力的时间、下一波是否使用及实际收益，不只看亏损金币。

## 六核是否需要黑皇杖

六名核心包括未购买者逐人完成以下判断，并在正文呈现理由与取舍；条件清楚可以写得紧凑，但不能省去某一维度：

- **职责与威胁**：什么干扰阻止本人输出、施法、前排或保护；本场补丁的黑皇杖能解决什么、不能解决什么。不能当作无条件免控免伤。
- **替代保护**：自身技能、站位、进场顺序、其他装备或队友保护能否替代；检查距离、资源和失效条件。多人不能重复占用同一次救人。
- **成本与时机**：买它会延后何种输出、机动、团队装或买活，在哪个目标窗口前需要。应当出不等于第一件出，暂缓不等于整场不出。
- **条件结论**：优先出、满足条件再出、可延后/不出或证据不足。写成模型判断，不因实际死亡或最终输赢反推必买。

双方分别点名三核配置，比较全出、部分出或阶段性暂缓，说明保护压力和团队节奏代价。结论可随阶段改变，不追求固定购买人数。反事实讨论机会和代价，不保证换装备必胜。

必要性与实际使用评价分开。先判断该不该买，再检查买后怎样用。

## 已持有者的实际窗口

从购买、库存、整场/窗口物品使用与补充日志交叉确认持有者。覆盖所有会改变本场评价的重要窗口，不仅挑最醒目的一波，也不要求一好一坏：

- 战前是否已经购买；送达、背包或冷却能否确认。
- 窗口内是否有主动使用，哪些动作或效果可被证实。
- 是否创造正确的输出、控制、生存或团队保护条件，随后转化了什么。
- 结束后谁获得第二轮窗口；没有时间戳和效果记录时不能还原顺序。

窗口总伤害不能等于黑皇杖期间伤害。未记录使用写明窗口前开启或持续效果未知，不说“有黑皇杖故意不开”。被动装备不按主动次数评价。没有负面案例不另写占位段落；完全没有可确认窗口则说明已查范围和限制。

## 每代肉山与持盾

逐代区分击杀方、正常拾取/抢盾事件、持有者与最终受益方；不能自动把击杀方当作持盾方。

围绕第一场相关战斗判断第一条命交换了什么、是否确为掉盾、复活后是否有接应和第二阶段价值，以及最终目标转化。缺位置、技能目标或录像时不虚构复活点安全性和吸收的技能；时间相近不证明死亡属于盾命。

盾命不只按伤害判断。低伤害可能失败，也可能换来队友的输出窗口，必须看资源交换与后续收益。只用实际证据支持的范围，不凑正反两代案例。

## 圣剑：当时能否保住并终结比赛

凡讨论某位英雄购买圣剑是否合理，必须同时分析持有者与队友的保剑能力、终结比赛能力，以及是否已需要承担圣剑风险来争取更高回报。先还原购买决策当时的局势，形成条件判断，再单独核对后续执行和结果；不能从最后获胜、失败、存活或掉剑倒推购买正确与否。该分析适用于双方所有实际购买者及用户提出的候选购买方案，不能只评价用户或最终持有者。

1. **决策时点与信息边界**：明确当时的经济差与资源压力、双方已知装备、存活与复活情况、可确认的技能/物品可用性、买活、兵线、建筑、视野和近期目标。购买不等于送达或能够立即使用；购买后才获得的装备、等级、队友资源与敌方信息不能反填进当时条件。用比赛中该时点之前的数据还原局势，不要求像开篇赛前博弈一样排除全部过程数据；但必须区分复盘能看到的事实与玩家当时可知信息。具体机制按该场补丁核验，缺失项逐项说明。
2. **持有者自身能否保剑并兑现输出**：分析自身生存、抗干扰、机动、输出距离、持续作战与撤离能力，已有装备与技能能解决哪些敌方威胁、仍怕什么；能否在安全条件下持续输出而非仅获得面板伤害。考虑当时经济投入、关键能力空缺与买活取舍，不以英雄名称或“有黑皇杖/有盾”直接判为安全。
3. **队友能否实际保剑**：点名负责先手、限制关键敌人、反手、救援、治疗、前排、视野与兵线的队友，说明保护如何形成，以及对手能怎样打断。区分“阵容中有这种能力”和“该时间点能提供”：核对存活、位置/接应条件、装备和技能状态，不把无法到场、资源耗尽或同时承担冲突任务的队友当作可靠保护；同一次救援不能重复计给多人。必要时讨论持有者阵亡或圣剑丢失后的接应/回收条件，不能把它当成当然能够兜底。
4. **持有者与队友能否终结比赛**：写清当时可行的目标链，例如限制关键守方 → 赢下交换 → 带线/推进 → 破高地或基地，并检查每一步需要谁来完成。结合推进与持续输出能力、兵线到位时间、保护续航、敌方守高地和清线手段、已知复活/买活状态、视野与地图路径，解释圣剑补上的是否正是缺失环节。不能把“输出更高”“能杀人”直接等同于“能结束比赛”；若目标只是守住关键一波或争取翻盘窗口，应如实区分短期止损与之后仍缺少的终结条件。
5. **是否不得不出：用更高风险争取更高回报**：先比较“不出圣剑”的现实前景：稳健装备、保留买活、拖延发育、目标交换等路线是否仍有可执行的胜利路径，还是只能延缓失利且关键窗口即将关闭。再说明圣剑具体能突破什么门槛——例如在有限输出时间内限制关键敌人、守住将失守的目标、反推或抓住对方防守资源不足的窗口——以及成功后能获得什么显著高于稳健方案的回报。回报以改变胜负机会和目标局势衡量，不只看伤害、击杀或金币增加。明确成功所需的最低保护、输出与队友配合条件，并比较失败代价：是否会丢失最后一波资源、扩大敌方优势或失去买活余地。
   保剑能力不完美不自动否定圣剑；当稳健方案已难以形成现实胜机，而圣剑仍能创造可执行的翻盘窗口时，承担更大风险可以是合理选择。反过来，若真正瓶颈是无法接近目标、无法输出或无人配合，而圣剑也不能改变这些条件，就不能因逆风认定“不得不出”。区分“仍可稳健争胜”“有理由主动博取更高回报”“常规路线近乎失效，圣剑是少数现实胜负手”与“证据不足”；只有充分比较当时可行替代后，才可接近“不得不出”的判断。不虚构胜率或期望收益数字，不用实际买了圣剑或最终输赢证明必要性。
6. **可行替代与最终裁决**：综合上述比较，分别回答“能否保剑”“能否终结或打开后续终结路径”“是否需要承担更高风险才能争取有意义的胜机”。比较圣剑现在出、满足条件再出或采用现实替代的机会成本，给出当时的推荐及主要失效风险。若判断必须冒险，具体写清不冒险会失去什么、圣剑争取什么更高回报、成功依赖谁和什么条件，不能停留在“只能赌”三个字。

正文在该英雄的装备分析中连贯写明“购买时判断”，随后用简短的“后续执行与结果”说明保护和终结条件是否兑现、在哪一步失效。后者用于评价执行与实际收益，不能改写前者的已知条件。合理购买也可能因后续失误或对手应对失败，不合理购买也可能被队友或对手失误掩盖。两项能力任一证据不足时，限制结论，不靠最终胜负补齐。

## 买活与用户路线

关键死亡前后检查实际买活、再次死亡和守塔/争盾/反推收益；实时余额、冷却未知时不能只凭最终金钱断言“有钱不买活”或装备必然挤占买活。

把影响局势的买活按完整战略周期分析，不只检查买活后的一次战斗：

1. **提前预留**：在关键装备购买和高风险行动前，判断预留买活是否能保住近期目标或第二轮作战机会，比较提前获得装备能力的收益与失去回场余地的代价。以当时可确认的经济、买活状态、兵线和目标压力为依据；不能因为后来死亡就倒推此前必须存钱。
2. **是否及何时买活**：死亡后评估自然复活与回到目标区域的时间、目标还能否挽救、队友能否等到或接应，以及买活后会得到何种收益。比较立即买、等待信息后再买与不买的现实后果；实际买活证明发生了该动作，不自动证明它必要或及时。不能假定对手会在等待期间停止推进。
3. **能否及时发挥作用**：核对可确认的回场方式、到达条件、装备状态、技能和物品可用性、队友剩余资源，判断回来之后能输出、控制、保护、清线还是只能拖延。把“买活”“及时到场”“改变交换”“守住或取得目标”分开核实，不把再次出现或最终守住直接归功于买活。对手可以撤退、转移目标或针对缺少第二次容错的英雄，替代方案需能承受合理应对。
4. **这一轮之后的风险**：检查再次死亡、关键技能消耗、己方后续回场余地与下一目标。逼出对方买活后，比较继续推进与撤退保留下一轮机会，说明继续投入需要什么兵线、资源和接应条件，以及撤退会放弃什么；不能把逼出买活自动等同于赢得交换，也不能默认对方买活后己方一定要撤。买活后的低风险收线、防守或等待也可能是必要调整，应结合双方局势判断。

复盘可见的敌方真实状态与决策者当时可知信息分别使用：前者解释实际交换，后者决定建议是否可执行。敌方未买活不证明没有买活；缺少可靠记录时，不能替决策者假定对方买活、关键技能或支援条件已知。涉及同一次买活的装备取舍、团战结果与十人评价引用同一条分析链，避免重复论证或重复计责。

用户路线重点识别首次参战质变、针对性取舍及真正影响战斗的真空期。存在问题才提出替代顺序和适用信号；原路线合理时明确说明，不强找最大失误。局部重打建议留在相关事件，最后的本人对局改进意见只提炼最多三条优先行动。
