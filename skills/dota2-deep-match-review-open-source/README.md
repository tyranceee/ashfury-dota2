# 开源版赛后复盘

用于 Dota 2 单场比赛的证据驱动复盘。入口为 [SKILL.md](SKILL.md)，工作流程按本轮任务选择：

- **独立完整复盘**：从原始数据建立事实账本，覆盖三路、职责、装备、技能、团战及个人改进。
- **协作精审**：核验同场初步复盘，深化装备、团战与贡献，披露抽查和重写范围。
- **专项追问**：沿用当前比赛，只分析所问英雄、决策或时间窗。

提供 Match ID、原始比赛 JSON 或同场初评即可启动；个人评价需要确认用户身份。账号、数据服务与输出位置从当前项目读取，不写死在技能中。没有可用初评也能独立复盘。

配套脚本只处理本地文件，使用 Python 3 和标准库。脚本示例路径以技能目录为基准；原始数据和已存在的输出文件均不覆盖。不能运行脚本的环境可以执行对应人工验收，但需说明限制。

报告以“全局博弈”为第一章，共七个章节，保留十人检查和逐次用户死亡；六核、四辅助和十人装备均保留过程与因果分析，共享事件通过引用去重。核心与辅助按完整清单逐人展开；每波团战先列双方英雄的窗口参战数据表，再写七阶段分析和本波总结，表格不替代分析。本人优先改进事项最多三条，不限制正文发现和局部改进。模型建议为 GPT-6 Astra + High，专项可用 Medium；属于可选建议，不自动改设置。

事实提取和机器门禁不能证明战术判断正确。缺少证据时给限定结论，不编造微观操作、技能目标或玩家意图。

复盘不会自动触发发布；发布时使用当前环境中可用的独立发布流程。只有用户提出发布要求时才交接已完成成稿；网址、会话及模型选择遵循当前项目配置和用户要求。
